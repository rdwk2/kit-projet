## Principes

1. **Si le code doit servir à d'autres** : aucun seuil propre à une personne dans le code ; tout
   cela se calcule depuis les données ou se déclare dans la configuration.
2. **Une question = une unité d'observation, une mesure, un facteur, des confusions
   nommées.** La méthode détaillée, les bases à battre et le nombre d'essais viennent dans le
   **plan d'analyse** de chaque question, relu avant le code (charte, § 6).
3. **« Déjà vue »** : une question dont une réponse a déjà été affichée sur les mêmes données
   reste exploratoire sur ces données ; elle ne se confirme que sur des données postérieures à
   sa déclaration (charte, § 5).
4. **Une première réponse simple d'abord** : l'appareil statistique vient une fois la question
   posée et une première mesure faite.

## Thème A — «…»

### Q1 — «la question, en une phrase»

- **Unité** : «sur quoi on observe (un individu, une journée, un essai…)»
- **Mesure** : «ce qu'on mesure, et comment»
- **Facteur** : «ce dont on veut connaître l'effet»
- **Confusions nommées** : «ce qui pourrait produire le même effet»
- **Statut** : déclarée le «date» · plan d'analyse : «à écrire | relu le … | fichier»
