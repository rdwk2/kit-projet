# Ressources du projet

Ce dossier reçoit ce qui décrit le projet de l'extérieur, tel que tu l'as reçu : le sujet, les consignes,
le barème, le calendrier, les données ou le code fournis, les échanges qui fixent le travail. Dépose-les
ici tels quels, en PDF, en texte ou dans n'importe quel format : pages web enregistrées, archives… Rien
n'est obligatoire : un dossier vide ne gêne personne.

- **Qui le lit** : la conversation A seule, qui y a accès avec `conception/`. La première A commence par
  lui : elle ne te pose que les questions auxquelles ces documents ne répondent pas. Les relectures B et C
  ne le voient pas : ce qui compte pour elles passe dans le brief.
- **Ce qui n'y va pas** : le code du projet (il est dans le dépôt), ce que la conception produit (dans
  `passations/`), et ce que tu ne veux montrer à aucune conversation.
- **Hors du dépôt** : ce dossier n'est jamais envoyé sur GitHub ni ailleurs. Un document à partager avec
  le groupe va dans le dépôt, par une PR.
- **Un document change** (nouvelle version du sujet, consigne ajoutée) : ajoute-le à côté, avec la date dans
  son nom, et dis-le à l'A en cours.

Fichier du kit : il revient à chaque mise à jour de l'espace. Tes documents, eux, ne sont jamais touchés.
